In the box

Admin, typed ORM, JSON API, MCP server for AI agents, semantic search, jobs and cron, live updates, webhooks, email, 2FA, row-level permissions, full-text search, CSV import and export, S3 uploads, a self-clearing cache, an N+1 finder. One binary. No Celery, no Redis.

Try it

On your Django database (nothing in it changes):

RANGOLI_DATABASE_URL=postgres://user:pw@host/db cargo run -p rangoli-django

Open /admin/, sign in with your Django account, click Connect an AI agent.
